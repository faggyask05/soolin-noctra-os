# Boot Flow

A boot élmény célja: minimál, sötét, egyedi, nem Windows, nem macOS, nem klasszikus Linux.

Sorrend:
1. Boot initialization
2. Core system awakening
3. Synchronizing services
4. Preparing environment
5. System ready
6. Awaiting authentication
7. Login screen

A boot screen Noctra jelenlétét sugallja, de nem tolja az arcba a brandet.
