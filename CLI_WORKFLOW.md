# CLI Workflow

A CLS verzió elsődleges felülete a terminál.

Fő parancsok:
- noctra help
- noctra install
- noctra install base
- noctra system check
- noctra profile
- noctra update

A Noctra Help nem statikus súgó, hanem interaktív terminál-alapú segítség.

Első bejelentkezéskor Noctra bemutatkozik, majd felajánlja az alap programok telepítését profil alapján.
