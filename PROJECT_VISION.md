# Project Vision

A Soolin Noctra OS célja egy olyan rendszer létrehozása, amely egyszerre otthonos fejlesztőknek, gamereknek és átlagos felhasználóknak.

A rendszer filozófiája:
- kevés erőforrás
- gyors működés
- CLI-first gondolkodás
- minimál, de használható GUI réteg
- Noctra mint rendszerentitás
- felhasználói igények alapján bővülő funkciók

Nem feature-halmozás a cél, hanem fókuszált rendszerélmény.
