# Stress Test Plan

## VM teszt - 1 hónap

### 1. hét
- rendszer boot
- terminál használat
- Git workflow
- böngésző teszt
- több terminál ablak

### 2. hét
- fejlesztés Rusttal
- Docker próba
- IntelliJ / VS Code próba
- hosszabb uptime

### 3. hét
- Steam telepítés
- közepes terhelésű játék teszt
- CS2 / Heroes jellegű játékok
- alt-tab / multitasking

### 4. hét
- napi használat
- memóriafigyelés
- crash logok
- frissítés teszt
- végső döntés: mehet-e natív tesztre

## Natív teszt - 1 hónap
- valódi hardver
- driver stabilitás
- Steam nagyobb játékok
- fejlesztés napi szinten
- GUI desktop fejlesztés előkészítése
