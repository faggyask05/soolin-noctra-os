# Soolin Noctra OS

A Soolin Noctra OS egy Arch Linux alapú, CLI-first operációs rendszerkoncepció.

Célja nem a Windows, macOS vagy Linux leváltása, hanem egy új felhasználói élmény megmutatása: gyors, stabil, letisztult rendszer, amelyben a felhasználó nem elveszik a gépben, hanem kapcsolatba lép vele.

Az első kiadás célja a CLS / CLI-first verzió:
- boot és login élmény
- Noctra CLI jelenlét
- alap programcsomagok telepítése
- fejlesztői, gamer, streamer és minimál profilok
- későbbi desktop patch előkészítése
